# 凡人修仙传-数据分析

这个仓库整理了《凡人修仙传》相关 B 站剧集数据、弹幕数据分析代码，以及已生成的分析结果。

## 目录结构

- `代码/Python/数据分析-项目/`：Python 数据采集、CSV 导入与分析脚本
- `代码/SQL/`：弹幕数据建表、清洗和查询 SQL
- `1结果/`：第一组分析输出图片
- `2结果/`：第二组分析输出图片和 PDF

## 数据与结果

项目包含：

- B 站剧集信息 CSV
- 弹幕数据 CSV
- 弹幕热度曲线图片
- 剧情高潮位置对比分析 PDF

## 说明

部分源文件可能使用了非 UTF-8 编码，直接在不同环境中打开时中文注释可能显示异常。运行或修改前建议确认编辑器的文件编码设置。
